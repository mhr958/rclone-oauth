# Personal rclone Google Drive Integration

This repository hosts the minimal web pages used for my personal Google Drive integration with [rclone](https://rclone.org/).

The integration is used solely for personal file synchronization and backup between my own computers and Google Drive.

## Purpose

This site provides the application information and privacy policy associated with my personal Google OAuth configuration for rclone.

This is not a commercial application or a service offered to other users.

## Privacy

The integration is intended solely for use by its owner.

This website does not collect, store, sell, share, or distribute personal information.

Google Drive access is used only for personal file synchronization and backup through rclone. Authentication and Google Drive access are handled by Google and rclone.

For additional information, see the [Privacy Policy](privacy.html).

## About rclone

rclone is an open-source command-line program for managing files on cloud storage services.

For information about rclone, visit the official website:

https://rclone.org/
